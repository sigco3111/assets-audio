Starember Field Synthesized SFX (별잿빛 들판 합성 효과음)

Original synthesis code: src/core/audio.ts of gamedemo_by_Fable5.2 (星烬原野)
by weit0529 - https://github.com/weit0529/gamedemo_by_Fable5.2 (MIT,
Copyright (c) 2026 weit0529). The upstream LICENSE applies to the code and is
included as LICENSE.txt.

The OGG files were rendered offline from the original WebAudio recipes by the
Korean localization project (https://github.com/sigco3111/gamedemo-by-fable5.2-ko);
the deterministic renderer tools/render_sfx.py is included. The in-browser engine
(engine/audio.ts) is included for web projects that prefer runtime synthesis.
